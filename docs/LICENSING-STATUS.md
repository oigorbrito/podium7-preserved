# Podium 7 Licensing Status

**Status:** `UNKNOWN`

Podium 7 does not currently declare a software license.

This is intentional: no redistribution, modification, sublicensing, or public-use rights are inferred or granted merely because the source code exists in the repository.

A future license is an explicit project-owner decision and must not be guessed from dependencies, repository visibility, source provenance, or development tooling.

## Packaging rule

Until a license is explicitly selected by the project owner:

- `pyproject.toml` must not claim a license identifier or license text;
- no `LICENSE` file should be generated from assumption;
- source-specific acquisition and evidence provenance remain separate from software licensing;
- any future license change must be explicit and reviewable.

This status is `UNKNOWN`, not `ENGINEERING_CHOICE`: choosing legal grant terms requires an owner decision outside the technical hardening process.
