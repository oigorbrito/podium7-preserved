# Agent Harness V1 execution record

Status: completed
Date: 2026-08-22

## Outcome

Refactored the repository-native development harness so future agents can start from `AGENTS.md` + current state, navigate to canonical documentation, execute autonomously through edit → validation → correction → PR/CI/merge, and stop only at an external blocker or non-inferable high-risk decision.

## Boundaries preserved

- No Codex/model login or model call.
- No Catalog identity/product semantic change.
- No software-license decision.
- Existing specialized design/product documents were indexed rather than moved cosmetically.

## Decisions

- `AGENTS.md` is a short map only.
- `docs/INDEX.md` is the progressive-disclosure entry point and `docs/` is the system of record.
- `docs/DEVELOPMENT-WORKFLOW.md` owns recurring autonomy, approval, Git/PR/CI, validation, self-review, done, and stopping policy.
- `docs/INVARIANTS.md` owns cross-cutting product invariants and points to specialized contracts for deeper rules.
- `docs/CURRENT-STATE.md` contains stable factual state only; `CURRENT-WORK.md` contains only active work.
- `docs/TECH-DEBT.md` owns durable unresolved debt/blockers.
- Volatile facts are generated by `scripts/project_facts.py` into ignored/CI artifacts.
- `scripts/check_harness.py` mechanically enforces required structure, bounded `AGENTS.md`, relative links, top-level docs indexing, freshness, short current work, and no manually copied volatile counters in current state/work.
- CI runs the harness checker, generates facts, runs runtime health, executes the isolated test suite, and publishes machine evidence.

## Validation protocol

The branch/PR for this execution record must pass:

```bash
python scripts/check_harness.py
python scripts/project_facts.py --output artifacts/project-facts.json
python -m podium7 health
python scripts/run_tests_one_by_one.py
```

Authoritative test/runtime/counter values live in the generated CI artifacts rather than this historical Markdown.

## External blocker unchanged

Public/package release remains blocked by the owner-controlled software-license decision recorded in [`../../TECH-DEBT.md`](../../TECH-DEBT.md) and [`../../LICENSING-STATUS.md`](../../LICENSING-STATUS.md).
