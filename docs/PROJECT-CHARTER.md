# Podium 7 Project Charter

Status: current authoritative charter

## Mission

Podium 7 is a private, evidence-driven automotive knowledge system for acquisition, integration, reconciliation, review, and export.

## Problem

The project must preserve conservative identity decisions, inspectable provenance, and repeatable validation while supporting private operation and operator workflows.

## Users

- repository maintainers;
- private operators;
- reviewers validating evidence-backed catalog outcomes;
- agents maintaining documentation and validation gates.

## Scope

- evidence-backed ingestion and acquisition;
- conservative identity resolution and review;
- canonical persistence and export;
- operational validation, installation, and closeout documentation;
- bounded source-specific acquisition and benchmark evidence.

## Non-scope

- public distribution or open-source release while the project remains private/proprietary;
- weakening review semantics to reduce review volume;
- product changes made only to satisfy documentation shape;
- undocumented external integration paths or policy bypasses.

## Principles

- false merges are worse than missed duplicates;
- ambiguous cases remain reviewable;
- provenance is part of the product;
- current authority must be singular and explicit;
- history remains available, but not as current truth.

## Status

`PRIVATE_PROPRIETARY` remains the governing software status.

Operational development and private use continue. Public release remains intentionally blocked until an explicit owner decision changes the license status.
