# Code of Conduct

Podium 7 collaboration should be professional, evidence-focused, and respectful.

## Expected behavior

- Discuss technical decisions on their merits and evidence.
- Be precise about uncertainty, limits, and failed experiments.
- Critique ideas and implementations without personal attacks.
- Respect privacy, confidentiality, and security boundaries.
- Do not use harassment, discrimination, threats, sexualized conduct, or deliberate disruption.

## Project spaces

This applies to repository issues, pull requests, reviews, discussions, project documentation, and project-related communication channels.

## Enforcement

Concerns should be raised privately with the repository owner when possible. Maintainers may edit or remove harmful content, restrict participation, close discussions, or take other proportionate steps needed to keep project collaboration safe and productive.
