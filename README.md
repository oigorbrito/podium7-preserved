# Podium 7

Podium 7 is an evidence-driven automotive knowledge acquisition, integration, reconciliation, and export system.

Current scope: `PODIUM7_SCIENTIFIC_FOUNDATION_AND_DOMAIN_V1`.

The repository begins with a minimal domain model for automotive identity, source/evidence, candidate facts, canonical facts, conflicts, and provenance. Architecture principles and the scientific baseline are recorded under `docs/`.

Run the domain tests with:

```bash
python -m unittest discover -s tests -v
```
